# Prompts de génération — « Le distributeur qui vend des souvenirs »

Tous les prompts sont en anglais, format **vertical 9:16**, avec obligations de style identiques :
photoréaliste, thriller surnaturel, rouge sombre + cyan froid, grain 35 mm, lumière volumétrique,
faible profondeur de champ, espace négatif sombre en haut/centre pour les sous-titres, aucun gore,
aucune déformation, aucun filigrane.

## 🧩 Astuces de continuité qui ont fonctionné

1. **Générer le décor et le personnage d'abord** (plans 2 et 3) puis les passer en référence pour tout le reste.
2. **Décrire les vêtements à chaque prompt** — jamais « le même manteau » seul : répéter
   `beige camel overcoat over a heather-grey crewneck sweatshirt`.
3. **Interdire le texte dans les plans sans texte voulu** : `no text or letters anywhere`
   (sinon l'IA ajoute de faux mots sur les affiches et les écrans).
4. **Toujours préciser la main à cinq doigts** : `anatomically correct hand with exactly five fingers`.
5. Pour un nouveau personnage ressemblant sans être identique : `keep the exact same young man as in the reference image` + la description complète (les deux, pas l'un ou l'autre).
